# 2026-10-12 學習日誌

## 今天學了什麼
今天研究 Claude Code 的兩個重要功能。第一個是 Skill：把常做的工作流程寫成一份說明檔，之後只要輸入指令，Claude 就會照著流程做，例如每天寫日記的引導。第二個是 MCP，它是讓 AI 連接外部工具的統一規格，就像 AI 的 USB 孔。我把網頁抓取工具和筆記工具接上之後，Claude 可以在對話中自己決定要不要使用。

## 遇到的困難
一開始不確定 Skill 和 MCP 差在哪裡。整理後的理解：Skill 是「做事的步驟說明」，MCP 是「可以呼叫的工具」。兩個可以搭配使用。

## 心得
把重複的事情變成 Skill，可以省下很多時間。下一步想試著自己寫一個最小的 MCP 工具。
